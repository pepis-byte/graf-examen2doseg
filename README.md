# Conclusiones

## 1. David MedinaMoreno

El desarrollo de este proyecto permitió crear exitosamente un entorno interactivo bidimensional en tiempo real mediante tecnologías web estándar: **HTML5 Canvas, CSS y JavaScript**, organizadas bajo una arquitectura modular de tres archivos. Se cumplieron los requerimientos técnicos y funcionales establecidos, logrando la renderización fluida de 25 objetos animados de manera simultánea, la implementación de distintos patrones de movimiento (rectilíneo, diagonal y circular) y la integración de mecánicas de colisión elástica mediante el cálculo de distancias euclidianas.

## 2. Lizbeidy Martinez Vargas

La implementación permitió comprender la importancia de optimizar los procesos de renderización, actualización de posiciones y detección de colisiones para garantizar un funcionamiento fluido. Como posibles mejoras futuras, se propone incorporar niveles de dificultad, un sistema de puntuaciones y técnicas de optimización que permitan gestionar una mayor cantidad de objetos sin comprometer el rendimiento de la aplicación.
